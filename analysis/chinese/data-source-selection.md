# 字形数据选型与转换

主来源为 **Hanzi Writer Data 2.0.1**（固定 npm 包），受控备用为 **Make Me a Hanzi `bddc96d41bef78427ed0e034e9f7e31d71fd1b92`**。两套资料来自共同的 Arphic 字形家族，双源比较用于发现包装、轮廓封口和版本差异，不能视为独立的笔顺交叉认证。[Hanzi Writer Data 原始说明](https://github.com/chanind/hanzi-writer-data)、[Make Me a Hanzi 原始说明](https://github.com/skishore/makemeahanzi)。

## 目标与许可

- 目标明确为 2013《通用规范汉字表》一级 **3500 个不同字符**，不是随机收集 3500 字。[教育部一级字表说明](https://www.moe.gov.cn/jyb_xwfb/xw_fbh/moe_2069/s7135/s7562/s7564/201308/t20130827_156334.html)。机器清单来自 `shengdoushi/common-standard-chinese-characters-table` 固定 revision `d9b599a9c9cc0dd2d58cad829e285bc780cd4451` 的一级表，完整内容保存在 `data/glyphs/targets.json`，来源与哈希写入 provenance。
- 仅使用图形数据，未引入受另一许可约束的 Make Me a Hanzi `dictionary.txt`。原笔画轮廓、中线、顺序属于 **Arphic Public License**；完整原文随部署保存在 `public/glyphs/ARPHICPL.TXT`。
- 每一分片含转换日期、修改说明、许可、无担保说明及来源索引。坐标归一化、度量、来源选择与盼字修复是本项目修改，修改数据按同许可自由提供；本项目其余独立代码不因此被误标为该字体许可。

## 同组比较与风险分层

代表组覆盖点、横折、钩、撇捺、封闭部件、多部件及高笔画复杂字：`一二三十永我心书中文名签国圆回风飞女水火山木王张李陈赵黄明德爱谢赢警藏戴曦麟齿凹凸卵`（实际目标表外字符不混入首期覆盖数）。

主源全量处理；代表组、每 97 字的审计样本、18 笔及以上、缺失和不合格字生成备用候选。完整两源结果、每笔内部比例、最大偏移、覆盖率、评分和入选来源见 `glyph-quality.json`。不在两源之间拼接单独的轮廓与中线。通过硬门禁后质量相近时优先主源。原型表明保留原楷体轮廓可直接输出完整笔画；原英文仍用原创单线，免于重写和字形风格漂移。

## 坐标与质量门禁

原 1024 坐标统一映射为 `x / 10.24, (900-y) / 10.24`，中文基线为 88；轮廓和中线使用同一变换，不拉伸字形。字宽、左右留白、基线、视觉偏移、bounds 均显式保存并由几何推导。SVG 曲线按不超过 2 原坐标单位的步长采样；保留用于渲染的原曲线，仅在检查面上处理自相触边。

硬检查包括配对笔数、有限坐标、封闭非空轮廓、非退化中线、原顺序及配对哈希、中线至少 90% 的密采样距对应轮廓不超过 2 原单位、任一点偏离不超过 32 原单位、全轮廓遮罩几何覆盖至少 99.9%。90% 与 32 原单位是初始几何筛查，不能替代视觉审计；动态显现和同步另有浏览器门禁。源中线重复相邻点可确定性去重，并重新检查。缺失或无法确认方向的骨架一律隔离，不把自动骨架推测当正式轨迹。

首次全量筛查 3499 合格、1 隔离，原失败报告保存在 `glyph-quality-before-repair.json`。盼的第七笔原直线离开弯曲捺画，最大偏离 37 原单位；修复保留起终点、方向和笔画顺序，沿轮廓内部补充路径点。独立顺序依据 [GF0023-2020《通用规范汉字笔顺规范》](https://jw.beijing.gov.cn/language/bzgf/202105/P020210512414220837538.pdf) 序号 1480 的 `251113453`，第七笔为捺。细节与复验记录在 `data/glyphs/repairs.json`，红色原中线 / 绿色修复中线叠图为 `repair-pan.png`。审查者为 Codex，未声称人类专家签字。

## 可复现流程

先执行 `node scripts/fetch-glyph-sources.mjs` 获取固定构建输入（也可预放相同版本源文件），再安装 `scripts/glyph-requirements.txt` 并执行 `npm run glyphs:build`。工具使用本地缓存，应用只加载 `public/glyphs/` 的本地分片。清单、分片、逐字报告、两源候选和完整 35 页图集由同一次构建生成。每次正式验收再用实际浏览器验证 SVG 遮罩和动画，不能只凭工具退出码宣称完整通过。
