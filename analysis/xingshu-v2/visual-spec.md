# 硬笔行书视觉规范 0.2.0

目标是中度硬笔行书、偏行楷：结构清晰、笔势自然、连笔克制、主笔饱满。本规范对应这次实际重画的「你」「好」，没有扩展其他汉字。

## 笔迹与压力

每 em 100 单位，x 向右、y 向下。两字 advance 均为 100，baseline 均为 88；正式产品排版另加原有 5 单位字距。比较材料统一使用 110 单位原点距离，避免不同版本的 advance 干扰形体判断。

主体多数为 3.8–5.6 单位；正常桌面 scale 1.65 时约 6.3–9.2 CSS px。提锋仅在末端短段降至 0.55–0.8，不把整段做成头发丝。点与长横末端保留 1.4–1.8 的短圆收；亻竖末端 2.0，避免所有笔都收成尖针。子部唯一接触点两端宽度均为 1.9。

十三笔都有独立压力序列，区分起笔、主体、转折与收笔：短按、斜切、轻落各有安排；撇由按压转为左下释放，竖微弓而饱满，横肩上扬且折前稍按，钩在转折处按压后提起。女第一笔的圆转由连续三次曲线组成，避免不合理尖角。不添加飞白、墨滴、随机噪声或毛笔式大锋。

闭合轮廓由弧长重采样中线与逐笔压力曲线生成。压力点间余弦插值保持连续，左右法向边界组成完整轮廓；不是对 SVG 统一放大 stroke-width。原 inkRenderer 不变，仍用同一中线揭示闭合轮廓，完成时释放遮罩。

## 部件结构

| 部件 | 本轮实际处理 |
| --- | --- |
| 亻 | 撇重画弧度，独立抬笔转入有力度的微弓竖；不再沿撇反走出细楔。部件紧凑、左低右高。 |
| 尔 | 上撇与横钩分别落笔，肩部右扬；竖钩承重并略向中宫收回。短撇和斜点向两侧舒展，长度与出锋不同。 |
| 女 | 三条主体全部保留。第一笔腰部圆折后短斜点收束，抬笔重落第二长撇；第三提右扬。清除外侧返回环，以交叉和方向保持女的辨识。 |
| 子 | 上肩略前倾；横撇尾部圆转，同点同向进入弯竖钩，钩前加按。长横低于女提，方向呼应而不跨部件连墨。 |

主笔的方向来自独立曲线与部件位置，没有整体 CSS skew。两字共同的上扬肩、饱满竖钩和短收笔形成一致风格；它仍是两字实验设计，不能据此自动批量生成全库。

## 连带与节奏

三条旧牵丝全部删除。13 逻辑笔画 / 12 连续动作组 / 13 墨迹段，只有好 4→5 直接接触；不存在独立牵丝段。其余笔间与字间均真实抬笔，离纸期间不改变墨迹。原编号、顺序、部件和 HWD 2.0.1 原笔画哈希保留，无省略和重排。

连带必须同时通过方向、收笔导向、空间、无回绕、辨识度和优于抬笔六项审查。源码规则和取舍见 [connection-review.md](connection-review.md)；笔顺相邻本身不是允许连墨的理由。

主笔约按每局部弧长 0.006–0.007 秒舒展，短撇与提较快；逐笔单调节奏曲线在入笔和钩折处安排按停。沿用 SignatureController 唯一 GSAP 时钟，共享 p 驱动实际 SVG 弧长、轮廓、3D 笔尖与阴影。正常「你好」实测约 5.5 秒，比旧原型约 5.17 秒略长，未用缩短总时长掩盖造型问题。

## 比较与审查

A 为全部独立抬落的克制型；B 只保留自然的子部接触。两个候选都有完整静态、逐笔图、中线叠图与正常速度浏览器录制，生产页面没有候选切换按钮。最终推荐 B，原型继续等待用户审美确认，不合 main。
