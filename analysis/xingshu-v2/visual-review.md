# 第二轮视觉审查与推荐

2026-10-30，Codex 根据 prompt_04 和用户两张图片的反馈实施。先在真实浏览器重新输入原「你好」「你」「好」，再比较重画候选；功能通过与最终用户审美分开记录。

## A / B 实际取舍

| 项目 | A 克制型 | B 自然连带型 / 最终推荐 |
| --- | --- | --- |
| 连笔 | 13 笔分别抬落，没有牵丝 | 仅子部 4→5 同点接触，没有牵丝；12 组动作 |
| 主笔 | 稳定、饱满，长竖和短点均有压力变化 | 长竖钩的按压稍强，短笔与主笔对比更清楚 |
| 女字旁 | 无返回环，腰部圆折清晰 | 同样取消返回环；长撇略舒展，斜点与提的收束更紧凑 |
| 子部 | 上部横撇与竖钩分离，有气口 | 横撇自然圆转进入竖钩，静态和运动更连贯 |
| 书写节奏 | 正常「你好」录制约 5.56 秒，抬落分明 | 约 5.50 秒，主笔舒展，仅一处省去抬笔 |
| 推荐 | 清楚、稳定，作为对照保留 | 在辨识和连贯之间更均衡，选为当前实验默认 |

最初还试画过一条更短的尔部返回线。同尺度浏览器截图中仍形成尖楔，未通过“效果优于抬笔”的条件，因此从 B 和最终版本删除；[弃用图](rejected-shoulder/normalized.png) 与源数据保留。没有为了让 B 连笔更多而强留连接。

## 静态观察

「你」左部收紧，撇与竖各自落笔；右肩、中央竖钩与短撇斜点的重量重新分配，左右之间以空间呼应。「好」女旁的三条主笔都在，外侧细环消失；子部整体上肩和弯钩共同形成向右上呼应的笔势。

已实际检查五版归一比较、A/B 全字和逐笔叠图、三条连接对照、最终正常产品画面与单字画面。最终两字同尺度蓝色墨迹面积为 30,921 像素，旧原型 17,890，增加约 73%；标准字形为 39,526。这个指标支持“笔迹更饱满”的观察，不代替美感或真实物理压力测量。

## 动画观察与客观证据

已检查最终 11 张正常动画关键帧及总览、真实视频解码帧、清除图和生产截图。中线与笔尖同向，三处旧连接改为清楚抬笔；子部转折没有反向回绕。截图的 p 在调用截图前记录，实际曝光期间动画继续，不把它冒充精确曝光进度。

自动化另验证：实际中线端点与 3D 投影同步；唯一接触点的屏幕间距为零；11 次空中移动均采到；三处删除位置的墨迹在抬笔期间完全不变；接触阴影与离纸阴影不同；完成轮廓精确显现；粒子来源位于实际完整墨迹中。数学投影误差与屏幕抗锯齿误差分开。

交互沿用写完保留签名、清除时铅笔归位的既有流程。没有独立 3D 时间线、回放控件、运行时候选按钮或手机专项。
