# 中英文混合书写扩展

## 目标与范围

按 prompt_02 建立 3500 一级字、数字标点、混排、完整笔画逐笔显现、真实 3D 同步、缓存及恢复系统，保留英文引擎。用户 2026-10-30 明确“先不考虑手机端吧”，本轮正式范围为桌面，移动专项暂缓而非通过。

## 结果与关键变更

产品源码与证据形成提交 `cc47a1b29e385261197a5899a2d3c8b3690b2ad3`，版本 1.1.0；其前冻结英文基线 `790d195` 已推送功能分支。后续报告与记忆提交不改变产品源码。开发隔离在 `feature/chinese-writing`，交付按根 AGENTS 的持续授权安全整合 main、推送并核对实际远程，不强推。

正式字库 3500 / 3500、33,959 笔、110 本地分片，目标内暂不支持 0。主来源 HWD npm 2.0.1，备用 MMH bddc96d；Agent 依据 42 字同组几何、137 风险字、40 字两源 80 次实际协调层动画比较选择，承认共同祖先，不当独立笔顺认证。保留 Arphic 许可原文与版本追踪。

初检盼的第七笔两源原中线均出轮廓，3499 / 3500 的原失败报告保留。按独立 GF0023-2020 顺序依据、原端点和方向修复，复验后 3500 合格；版本化记录、叠图、复验均可追溯。确定性重复点自动修复；缺失 / 坏中线尝试真正的骨架路线候选，但保持隔离，未经独立复核不能入库。

完整中文轮廓与中线遮罩共用动作时钟；原英文短签名路径 / 时序保留。注册表 grapheme 预检列出全部问题位置，保留空格、标点和手动换行。textarea / IME、多行禁则、固定布局、双层 LRU 和活动 lease、卸载取消、动态偏好安全边界、逐笔完整区域粒子及自适应降级全部集成。
