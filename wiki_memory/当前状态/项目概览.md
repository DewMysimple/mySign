# 项目概览

## 项目目标与阶段

目标是依据参考视频和提示词，实现可输入英文姓名的实时 3D 签名网页：白色铅笔逐笔写出蓝色签名，橡皮擦触发粒子消散并归位。当前已具备可运行的前端实现、557 帧视频分析、模型及浏览器测试。实现范围与固定英文笔迹的限制见根目录 README；不把生成每人独有书法或中文支持视为已完成能力。

本轮维护接入 standard 工程记忆和 Git 远程管理，不新增产品功能、不修改应用逻辑。产品需求依据为 `prompt/prompt_01.txt`，实际入口和状态依据为 `src/App.jsx`。

## 核心入口

- 页面：`index.html` → `src/main.jsx` → `src/App.jsx`；控件在 `src/components/SignatureInput.jsx`。
- 笔迹与动画：`src/handwriting/`、`src/animation/SignatureController.js`；3D 与粒子在 `src/scene/`。模块关系见系统架构页。
- 启动与验证：根目录 `README.md`、`package.json`、`playwright.config.js`；`runStart.cmd` 是本机开发启动脚本。
- 视频证据：`analysis/视频逐帧分析.md`、`analysis/frame-metrics.csv`、八张连续图组；最终应用证据在 `analysis/verification/`，`analysis/app/` 为早期迭代记录。
- 工作约定：根目录 `AGENTS.md`；记忆导航与协议在 `wiki_memory/`。
