# 已知问题

## 未解决问题与影响

本轮桌面门禁未发现待修复的功能缺陷；检查范围为本机 Chrome 全面、Edge / Firefox / WebKit 关键回归与生产预览，不是所有设备保证。

| 边界 | 影响 |
| --- | --- |
| 正式字集 | 一级 3500 字与符号注册表外仍拒绝，例如曦、麟、Emoji、重音字母；字形固定 |
| 手机专项暂缓 | 用户明确先不考虑手机端；未做 iOS / Android 真机 IME、触摸与低动态认证 |
| 运行环境 | 需 WebGL；性能来自本机桌面允许 SwiftShader 环境，其他 GPU / 低端设备帧率未知 |
| 生产包体 | JS 944.26 kB / gzip 276.87 kB，Vite 大 chunk 提示仍在，构建成功 |
| 图集审查范围 | Codex 已逐页目视检查，不代表人类书法专家逐字认证；两源有共同祖先 |
| 固定布局 | 书写期间缩小视口只改映射，保持既定换行，可能继续缩小字号；再次提交才重新排版 |
| 托管与柔影 | 未部署公网，无账户或持久化；柔影是实时阴影贴图近似 |

## 复现与临时处理

范围外输入保留原文并显示全部问题字符与 1 起始位置；扩展字集需路径、顺序、度量、质量与动画验证后注册。大规模文本超预算时拆分或扩大窗口，不自动截断。

改动后按 README 选取模型、流水线、浏览器和生产复验；数据重建会生成候选，不能绕过图集 / SVG / 动画门禁直接发布。聚合脚本校验现有证据，不代替实际重跑。

已解决的盼中线、遮罩边缘、缩放首帧竞争保留失败报告与截图，见 acceptance；不再列作当前未解决项。`glyph-quality.json` 的 NOT_RELEASED 是几何阶段快照，正式字库状态看 qualification，完整桌面状态看 acceptance。
