## 复现与临时处理

- 非英文姓名触发原生校验，现阶段使用英文字母及空格；扩展字符需同时补笔画、布局及校验，不能只放开正则。
- 超长姓名整体缩小，可用短姓名验证交互；布局变化应覆盖长短名、上伸/下伸字母及窄屏。
- `npm run build` 核查实际包体与提示；需要优化首屏时再据分析拆包，不将阈值提示当作构建失败。
- `npm run test:e2e` 覆盖标准交互、同步、缩放、重复提交及低动态；生产复验先 build / preview，再执行 `node scripts/verify-production.mjs`。这些是复验方法，本轮未运行。
- 非 WebGL 环境显示错误状态，暂无替代铅笔实现；跨浏览器问题需在对应环境复现，不能用已有截图证明真机可用。
