# 系统架构

## 模块职责与边界

纯客户端 React / Vite / Three.js / GSAP，无后端、账户或持久化，无新增依赖。

| 模块 | 当前职责 |
| --- | --- |
| App / SignatureInput | React 生命周期、固定一行 textarea、IME、忙碌锁、原文和无障碍播报 |
| glyphs / signature / symbols | 原英文字形与连笔、精确边界、数字标点；原英文几何不变 |
| writingPlan / signatureLimits | 注册表预检、单行布局和可配置预算、逻辑笔画与视觉组映射 |
| xingshuRegistry | 两字不可变实验数据覆盖，正式 manifest 保持原样 |
| GlyphLoader / GlyphCache | 其余标准字的本地完整性、双层 LRU、取消和活动引用保护 |
| motionRhythm / SignatureController | 单调逐段节奏；唯一 GSAP 时钟，驱动接触 / 抬笔、遮罩、3D、偏好和恢复 |
| inkRenderer | 原完整轮廓 / 中线遮罩函数未改；每段完成释放遮罩保全边缘 |
| PencilScene / InkParticles | 原真几何、实时柔影、完整区域采样和清理源码未改 |
| build-xingshu | 仅两字独立曲线 / 压力轮廓、图集、可编辑源码和许可副本；不写正式字库 |

13 个原逻辑笔画分为 9 连续组；3 牵丝为独立视觉段，16 墨迹段由既有协调层执行。组内端点相同，不插入空中移动；跨组仍抬笔。原编号、结构、来源哈希不因连写而删除。

## 数据流与依赖

原文 → grapheme 注册表与字符数预检 → 本地 glyph lease（两字选择不可变实验数据）→ 单行宽度 / 段数 / 时长预检 → 固定墨迹与移动计划 → 实际 SVG 弧长 → 唯一 GSAP 共享 p → 遮罩、3D 笔尖与阴影。

坐标仍为字形局部、单行排版、视口 / Three 三层；resize 同帧更新 SVG 和相机，不重排既定笔序。低动态保持当前动作，后续使用简化参数；故障取消异步与时间线、清理墨迹、复位并保留原文。缓存仍各 2 MiB，活动引用受保护，释放后收敛。

两字新的三次曲线与压力轮廓由 Agent 在授权任务中制作，HWD 2.0.1 只作逻辑顺序 / 结构参考；不是字体轮廓追踪或自动骨架推导。沿用 Arphic 许可，独立 public/experiments 分发源码 / 许可。Long Cang 仅视觉研究，没有进入运行时。

## 运行与部署

Node 22.12+，`npm ci`、`npm run dev`；本工作树预览 `npm run build`、`npm run preview`。两字实验数据随 JS，3500 字标准库仍独立分片；只请求本地文件，不上传输入或加载在线字体。

`npm test`、`npm run test:e2e`、`npm run test:desktop`、`npm run test:production`；原型生成 / 显现 / 校准命令见 README。`verify-xingshu-acceptance.mjs --check` 只读核对报告指纹，不重跑测试。修改渲染或字形后须复验受影响范围。
