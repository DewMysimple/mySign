# 系统架构

## 模块职责与边界

纯客户端 React / Vite / Three.js / GSAP 应用，没有后端、账户或持久化。

| 模块 | 实际职责 |
| --- | --- |
| App / SignatureInput | 生命周期、textarea、IME、忙碌锁、错误与屏幕阅读器状态 |
| glyphs / signature | 原 52 英文字形、连笔、Bézier 边界和坐标；短英文原几何与时序保留 |
| symbols / writingPlan | 数字标点、grapheme 注册表预检、保留原文、禁则换行与固定动作计划 |
| GlyphLoader / GlyphCache | 110 个本地分片、长度 / SHA256 / schema 校验、双层 LRU、取消与任务引用保护 |
| inkRenderer | 中文完整轮廓配对中线遮罩；每笔完成释放遮罩，保全完整边缘 |
| SignatureController | 唯一 GSAP 时钟、SVG / 笔尖 / 阴影同步、偏好边界切换、清除及异常恢复 |
| PencilScene / InkParticles | 真几何铅笔、正交投影、实时柔影、完整轮廓采样及逐笔延迟粒子 |
| build_glyphs 等 | 固定来源转换、检查、修复、骨架隔离候选、图集与证据门禁 |

实现 Agent 按授权选择主 HWD 2.0.1、受控 MMH 备用，二者共同祖先不算独立笔顺认证。原始配对优先；自动骨架候选保持隔离，独立复核后才可形成版本化修复。正式汉字使用 Arphic Public License，修改和来源随数据交付。

## 数据流与依赖

原文 → grapheme 预检 → 本地字形 lease → 固定行框和笔画 / 移动 / 收笔计划 → SVG 实际弧长 → GSAP 共享动作进度 → 同一次 render 更新遮罩、3D 笔尖和阴影。坐标分字形局部、文本排版、视口三层；窗口缩放只更新映射，不重新换行。resize 事件与逐帧尺寸检查避免首帧 SVG / 相机竞争。

状态为 `idle → preflighting → writing → written → erasing → idle`。低动态实时监听：保留当前动作，后续动作改参数，立即降低非核心效果；清除保存启动时偏好，避免切换时墨迹回显。持续慢帧仅降低 DPR / 粒子预算。异常保留输入、取消异步和时间线、清理临时墨迹、复位再允许重试。

缓存各 2 MiB 为保守计费预算，活动引用可受保护超预算，释放时收敛。缓存仅留纯数据，React 重挂载可重用；卸载释放事件、GSAP、WebGL 与临时资源。空闲 / 完成状态不持续渲染。阴影保留纸面 customDepthMaterial 与 shader 采样展开，避免 VSM 自遮挡及 ANGLE 警告。

## 运行与部署

Node 22.12+；`npm ci`、`npm run dev`，或 `runStart.cmd`。构建 `npm run build`，预览 `npm run preview`，均为本机服务，未配置公网托管。运行时只读本地分片，不依赖在线字库、字体或上传输入。

模型 `npm test`，完整 Chromium `npm run test:e2e`，其他桌面 `npm run test:desktop`，生产 `node scripts/verify-chinese-production.mjs`。数据重建和门禁次序见 README，重建生成候选后需重新审查及 qualify，不能沿用旧证据自动发布。
