# 系统架构

## 模块职责与边界

这是纯客户端单页应用，没有已实现的后端、用户账户或签名持久化服务。

| 模块 | 实际职责 |
| --- | --- |
| `App.jsx` / `SignatureInput.jsx` | React 状态与场景生命周期、输入校验、Enter / 按钮提交、忙碌状态、无障碍状态文本 |
| `handwriting/glyphs.js` | 52 个原创英文大小写中心线字形，保存字宽及按顺序执行的笔画 |
| `handwriting/signature.js` | 输入规范化、路径构造、连笔与空格、三次 Bézier 极值、布局与屏幕映射 |
| `animation/SignatureController.js` | 唯一 GSAP 时间线、落笔与抬笔、SVG 揭示、3D 位置、擦除、ResizeObserver 与资源释放 |
| `scene/PencilScene.js` / `softPaperShadow.js` | 真几何铅笔、正交相机、实时 VSM 投影、纸面局部柔影过滤 |
| `scene/InkParticles.js` | 按实际 SVG 中心线采样，在单个 Canvas2D 绘制擦除粒子 |

用户提示词指定真实 3D、真实笔画及统一时间线；实现 Agent 在此前授权开发中选择原创字形以直接表达笔顺，代价是风格固定、字符集有限。柔影选择实时阴影贴图的面积光近似，代价是不同于离线路径追踪；两项均已实现，不是待选方案。

## 数据流与依赖

输入姓名 → `isSupportedName` → `buildSignature` 有序笔画 → SVG path 实际弧长 → GSAP 共享进度 → 同一次 `render()` 同步 dashoffset、路径采样位置、切线、3D 笔尖及投影。不能改成互不关联的文字和铅笔计时器。

React 展示 `idle → writing → written → erasing → idle`，控制器同步锁阻止冲突时间线。擦除同时淡出墨迹、绘制采样粒子并归位铅笔，最后清空姓名和恢复焦点。尺寸变化重算布局、相机及当前采样点；低动态模式缩短动画并跳过粒子。

运行依赖仅 React / React DOM、Three.js、GSAP，版本锁在 `package-lock.json`；不下载字体或模型，不上传姓名。空闲和完成状态不持续渲染；卸载释放时间线、监听器、几何、材质、阴影纹理与 WebGL 上下文。

阴影修改须保留两项处理：纸面 `customDepthMaterial` 防止 VSM 把接收面误作遮挡物；32 次采样按 Three shader pragma 展开，避免 ANGLE 循环导数警告。修改后需实际查看阴影及浏览器控制台。

## 运行与部署

- Node 22.12+；新机器先 `npm ci`，`npm run dev` 默认 127.0.0.1:5173；也可运行 `runStart.cmd`。
- `npm run build` 生成 `dist/`，`npm run preview` 默认 127.0.0.1:4173。GitHub 用于源码管理，本轮未配置 Pages、持续部署或公网托管。
- `npm test` 验证路径和布局模型；`npm run test:e2e` 用 Playwright 启动开发服务，优先本机 Chrome，也可设置 `CHROME_PATH` 或安装 Playwright Chromium。
- 生产复验先 build / preview，再运行 `node scripts/verify-production.mjs`，验证真实生产包交互及不暴露开发调试接口。
- 视频分析独立依赖 Python / OpenCV / NumPy / Pillow，网页运行不需要 Python。详见根目录 README。
