# 当前约束

## 用户要求与技术约束

- 用户明确选择 standard 工程记忆；根目录 `wiki_memory/` 为唯一有效记忆根，五份状态页和六类日志保留，不自行降为 lite。
- 用户授权初始化本项目 Git 并推送 `https://github.com/DewMysimple/mySign.git`；**今后每次完整对话产生的项目修改都要提交并推送**。覆盖源码、配置、文档和记忆，无需每轮再次请求许可；详见根目录 `AGENTS.md`。
- 产品遵循 `prompt/prompt_01.txt`：极简构图、真实程序化 3D 铅笔、笔尖与墨迹统一进度、Canvas 粒子擦除和归位，不以静态图、预渲染视频或完整文本淡入替代。
- 当前仅支持 ASCII 大小写字母和空格，不支持中文、重音、数字及标点；字形固定，不宣称生成用户独有签名或逐像素复刻视频字形。
- 保持 React / Vite / Three.js / GSAP 结构，新增依赖有实际理由；保留连写、重复提交锁、响应式、低动态和资源清理行为。

## 兼容性与操作边界

当前本机验证目标为 Windows Chrome / Chromium；浏览器需支持 WebGL。设备像素比上限 2，数学坐标误差与实际抗锯齿、设备帧率是不同指标。跨浏览器及真机验证缺口见已知问题页。

Git 默认交付分支 `main`、指定远程 `origin`。每轮开始核对实际 upstream 和远程引用；完成时审查差异、运行适当验证、同步必要记忆、提交相关文件、推送并核对实际远程 SHA。无修改的只读对话不创建空提交；失败时保留成果并说明恢复位置。不覆盖无关改动、不强推或重写远程历史。

授权限于本项目维护及指定 GitHub 源码远程；没有配置公网部署或其他外部服务的要求。原始提示词及视频保持原状；依赖和构建产物按 `.gitignore` 排除，凭据、密钥不得进入提交或记忆。
