# 当前约束

## 用户要求与技术约束

当前 prompt_03 明确采用中度硬笔行书、仅「你」「好」高质量原型、桌面单行。它替代 prompt_02 的自动换行、多行、8 行限制与 Shift+Enter 换行要求；手机端完全不纳入本轮优化。

32 可见字符（含空格）、140 墨迹段（含牵丝）、正常预计 40 秒、最小 scale 0.5 及实际单行宽度共同约束提交；测量见本轮 calibration。超限或换行拒绝且保留原文，不截断、不删除、不换行、不无限缩小字号容纳新提交。IME 组合输入 Enter 不提交，Shift+Enter 不换行。

保持最简纸面、蓝墨、真 3D 白笔、原英文、完整闭合笔画及唯一 GSAP 时钟，不加模式 / 重播 UI。逻辑笔画与实际连续动作分开；主体省略或实质笔顺变更必须单独说明和复核，不能静默混入。

原 3500 合格标准字、来源、许可与 manifest 保持可恢复；只生成独立实验两字。不能把 Codex 检查当人类书法专家认证，也不能把两字成功说成全库行书化。用户审美未确认之前，不合 main、不开展批量扩字。

## 兼容性与操作边界

Chromium 完整、Edge / Firefox / WebKit 关键、生产桌面 DPR1/2/3 验证。需 WebGL；慢帧仅降低非核心画质，不能改变中线、完整轮廓、顺序或同步。手机真机、其他 GPU、外网托管不作通过声明。

用户持续授权每轮项目修改提交推送，含文档和记忆。唯一 origin 为 `https://github.com/DewMysimple/mySign.git`；通常默认 main，但本次 prompt_03 明确要求先交付 `feature/chinese-xingshu-prototype`，审美确认前禁止合并 main。

开始实查工作树 / upstream / 远程，收尾审查本任务差异、验证、记忆并核对远程 SHA。不覆盖无关修改、不强推、不重写远程；失败保全成果。不提交依赖、dist、临时测试目录、字体研究缓存或凭据；请求的截图 / 轨迹 / 视频是正式分析交付物。

## 证据与未核实项

2026-10-30 依据用户 prompt_03、实际产品 8073018 和本轮测试核实。预算是桌面原型校准的产品边界，不声称所有字符 / GPU 的绝对性能极限。最终审美与进一步扩字需要用户新的决定，不从本轮功能通过推定授权。
