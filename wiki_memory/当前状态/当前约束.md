# 当前约束

## 用户要求与技术约束

- 用户指定 standard 工程记忆，唯一记忆根 `wiki_memory/`，保留五份状态页和六类日志，不自行降级。
- `prompt_01` 的极简构图、真实 3D 铅笔、笔尖 / 墨迹共享进度、粒子清除与归位继续有效；`prompt_02` 扩展中文完整笔画、真实有序中线、混排、质量和工程门禁。
- 用户明确本轮先不考虑手机端，桌面 Chrome 完整、Edge / Firefox / WebKit 关键回归保留；移动专项为暂缓，不能把模拟或桌面 WebKit 标为真机验收。
- 字形正式范围为一级 3500 字、52 英文字母、数字及常用标点白名单、ASCII 空格 / LF。仅统一必要换行符，不删字、折叠空格或悄悄替换字符。曦 / 麟等范围外汉字仍拒绝。
- 固定字形风格，不宣称每人独有书法。中文完整轮廓不能以细中心线代替，原配轮廓 / 中线不能未经验证混源。骨架候选不代表真实笔顺，未复核候选必须隔离。
- 保留 React / Vite / Three.js / GSAP、原英文几何、共享动作时钟、低动态与资源清理。系统动态偏好实时跟随，不增加开关、重播或额外可见控件。
- 当前任务预算经桌面原型校准：420 笔、正常预计 95 秒、8 行、最小排版 scale 0.36；超限原文保留。指标及环境界限见 `analysis/chinese/performance/budgets.json`。

浏览器需支持 WebGL；DPR 上限 full 2、reduced 1.25、economy 1。数学投影误差不同于抗锯齿与所有设备帧率。手机专项、其他 GPU 和公网部署未验收。

用户自 2026-10-29 持续授权：每次完整对话产生的项目修改均需提交并推送，包含源码、配置、文档和记忆，无需再索许可。唯一指定远程 `origin=https://github.com/DewMysimple/mySign.git`，默认交付 `main`；功能先隔离分支，门禁通过后安全合并。
