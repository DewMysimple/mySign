# 当前约束

## 用户要求与技术约束

prompt_04 的风格为中度硬笔行书、偏行楷：结构清晰、笔势自然、连笔克制、主笔饱满。仅你、好两个实验字，用户最终审美确认前不合 main、不扩字。两张参考图用于理解少连笔、增主笔和重画女旁的方向，没有追踪字体轮廓。

桌面单行，32 可见字符（含空格）、140 墨迹段、正常预计 40 秒、最小 scale 0.5 及实际宽度共同约束。不截断、不自动换行或无限缩小；换行 / 超限拒绝且保留原文。IME Enter 留给输入法，Shift+Enter 不换行。新版15个你/好组合约37.67秒，16字超40秒拒绝，预算未放宽。

保持最简纸面、蓝墨、真实 3D 白笔、完整闭合轮廓和唯一 GSAP 时钟；无生产模式切换、重播等新控件。A/B 仅在独立研究服务和交付页比较。

逻辑编号、来源、顺序和主体完整保留。连墨须独立满足方向、收笔导向、空间、无回绕、辨识和优于抬笔六条件；相邻笔顺不自动授权连接。被删线必须同时从墨迹、计划、3D轨迹和粒子输入删除。

## 兼容性与操作边界

本轮重验 Chromium 完整、Edge / Firefox / WebKit 关键、生产桌面 DPR1/2/3；需 WebGL。慢帧只降非核心画质，不能改中线、顺序或同步。无手机专项或其他 GPU 保证。

持续授权每轮项目修改提交推送（含文档和记忆），唯一 origin https://github.com/DewMysimple/mySign.git。通常默认 main，但本轮 prompt_04 明确仅交付现有实验分支 feature/chinese-xingshu-prototype。保全无关修改、不强推或重写远程历史，失败保全成果。不提交依赖、dist、临时测试目录或凭据；任务请求的真实材料属于正式交付。
